## Part 2. Bootstrap Grid System

### Task 2. Bootstrap Responsive Columns

Created three responsive columns using Bootstrap's 12-column grid:
- Mobile: each column takes 12 columns.
- Tablet: each column takes 6 columns.
- Desktop: each column takes 4 columns.

### Task 3. Bootstrap Navigation Bar

Created a Bootstrap navigation bar with a logo on the left and links on the right. On smaller screens, the navigation bar collapses into a hamburger menu.
